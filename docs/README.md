# Геометрический калькулятор

## Общее описание решения

Данный проект представляет собой набор функций для вычисления параметров различных фигур. 
  
В текущей версии реализованы вычисления для круга и квадрата.
  
Проект состоит из модулей, каждый из которых отвечает за работу с определенной геометрической фигурой.

## Описание функций

### [Модуль circle.py](../circle.py)

#### area(r)
Вычисляет площадь круга по заданному радиусу.

**Параметры:**
- `r` (int|float): радиус круга

**Возвращаемое значение:**
- float: площадь круга

**Пример вызова:**
```python
from circle import area

#Вычисление площади круга с радиусом 5
result = area(5)
print(result)  #78.53981633974483

#Вычисление площади круга с радиусом 2.5
result = area(2.5)
print(result)  #19.634954084936208
```

#### perimeter(r)
Вычисляет длину окружности по заданному радиусу.

**Параметры:**
- `r` (int|float): радиус круга

**Возвращаемое значение:**
- float: длина окружности

**Пример вызова:**
```python
from circle import perimeter

#Вычисление длины окружности с радиусом 5
result = perimeter(5)
print(result)  #31.41592653589793

#Вычисление длины окружности с радиусом 2.5
result = perimeter(2.5)
print(result)  #15.707963267948966
```

### [Модуль square.py](../square.py)

#### area(a)
Вычисляет площадь квадрата по заданной стороне.

**Параметры:**
- `a` (int|float): длина стороны квадрата

**Возвращаемое значение:**
- int|float: площадь квадрата

**Пример вызова:**
```python
from square import area

#Вычисление площади квадрата со стороной 5
result = area(5)
print(result)  #25

#Вычисление площади квадрата со стороной 3.5
result = area(3.5)
print(result)  #12.25
```

#### perimeter(a)
Вычисляет периметр квадрата по заданной стороне.

**Параметры:**
- `a` (int|float): длина стороны квадрата

**Возвращаемое значение:**
- int|float: периметр квадрата

**Пример вызова:**
```python
from square import perimeter

# Вычисление периметра квадрата со стороной 5
result = perimeter(5)
print(result)  # 20

# Вычисление периметра квадрата со стороной 3.5
result = perimeter(3.5)
print(result)  # 14.0
```

## Math formulas
### Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
