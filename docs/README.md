# Геометрический калькулятор

## Общее описание решения

Данный проект представляет собой набор функций для вычисления параметров различных фигур. 

В текущей версии реализованы вычисления для круга, квадрата, прямоугольника и треугольника.

Проект состоит из модулей, каждый из которых отвечает за работу с определенной геометрической фигурой.

## Описание функций

### [Модуль circle.py](../src/circle.py)

#### area(r)
Вычисляет площадь круга по заданному радиусу.

**Параметры:**
- `r` (int|float): радиус круга

**Возвращаемое значение:**
- float: площадь круга

**Пример вызова:**
```python
from circle import area

#Вычисление площади круга с радиусом 5
result = area(5)
print(result)  #78.53981633974483

#Вычисление площади круга с радиусом 2.5
result = area(2.5)
print(result)  #19.634954084936208
```

#### perimeter(r)
Вычисляет длину окружности по заданному радиусу.

**Параметры:**
- `r` (int|float): радиус круга

**Возвращаемое значение:**
- float: длина окружности

**Пример вызова:**
```python
from circle import perimeter

#Вычисление длины окружности с радиусом 5
result = perimeter(5)
print(result)  #31.41592653589793

#Вычисление длины окружности с радиусом 2.5
result = perimeter(2.5)
print(result)  #15.707963267948966
```

### [Модуль square.py](../src/square.py)

#### area(a)
Вычисляет площадь квадрата по заданной стороне.

**Параметры:**
- `a` (int|float): длина стороны квадрата

**Возвращаемое значение:**
- int|float: площадь квадрата

**Пример вызова:**
```python
from square import area

#Вычисление площади квадрата со стороной 5
result = area(5)
print(result)  #25

#Вычисление площади квадрата со стороной 3.5
result = area(3.5)Я
print(result)  #12.25
```

#### perimeter(a)
Вычисляет периметр квадрата по заданной стороне.

**Параметры:**
- `a` (int|float): длина стороны квадрата

**Возвращаемое значение:**
- int|float: периметр квадрата

**Пример вызова:**
```python
from square import perimeter

# Вычисление периметра квадрата со стороной 5
result = perimeter(5)
print(result)  # 20

# Вычисление периметра квадрата со стороной 3.5
result = perimeter(3.5)
print(result)  # 14.0
```

### [Модуль rectangle.py](../src/rectangle.py)

#### area(a, b)
Вычисляет площадь прямоугольника по заданным сторонам.

**Параметры:**
- `a` (int|float): длина первой стороны прямоугольника
- `b` (int|float): длина второй стороны прямоугольника

**Возвращаемое значение:**
- int|float: площадь прямоугольника

**Пример вызова:**
```python
from rectangle import area

# Вычисление площади прямоугольника со сторонами 5 и 4
result = area(5, 4)
print(result)  # 20

# Вычисление площади прямоугольника со сторонами 3.5 и 2
result = area(3.5, 2)
print(result)  # 7.0
```
### [Модуль triangle.py](../src/triangle.py)

#### area(a, h)
Вычисляет площадь треугольника по основанию и высоте.

**Параметры:**
- `a` (int|float): длина основания треугольника
- `h` (int|float): высота треугольника, проведенная к основанию

**Возвращаемое значение:**
- float: площадь треугольника

**Пример вызова:**
```python
from triangle import area

# Вычисление площади треугольника с основанием 5 и высотой 4
result = area(5, 4)
print(result)  # 10.0

# Вычисление площади треугольника с основанием 3.5 и высотой 2
result = area(3.5, 2)
print(result)  # 3.5
```

## Math formulas
### Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
